## Shot List Per Card

For **each** of the 5 cards (+ Mantle), capture:

### A. Primary — Front straight-on (SHOP HERO)
- [ ] Full slab in frame, cert label visible
- [ ] Card art centered, no keystone tilt
- [ ] No glare on grade number or cert #
- [ ] Resolution ≥ 2400 × 3360 px
- [ ] File: `slabs/{year}-{set}-{player}-front-{grader}{grade}.webp`

### B. Cert close-up (TRUST / LISTING PROOF)
- [ ] Tight crop on PSA/SGC label — cert # readable at 100% zoom
- [ ] Grade badge sharp
- [ ] File: `slabs/{year}-{set}-{player}-cert-{grader}{grade}.webp`

### C. 45° angle (DEPTH / CONDITION)
- [ ] Shows case thickness, corner integrity through case
- [ ] Subtle shadow for dimension — not dramatic
- [ ] File: `slabs/{year}-{set}-{player}-angle-{grader}{grade}.webp`

### D. Social crops (PRIYA — post-shoot)
- [ ] Square 1080×1080 — Instagram feed
- [ ] Portrait 1080×1350 — Card of the Day
- [ ] Export from master front shot; do not re-shoot

## Studio Setup (Priya)

```
        [Key light 45°]
              ↓
    ┌─────────────────┐
    │   SLAB (tripod) │
    └─────────────────┘
   ↗                 ↖
[Fill]              [Rim — kills background]
```

| Setting | Value |
|---------|-------|
| Background | Neutral gray `#e8e8e8` or black velvet |
| White balance | 5500K (daylight) — recalibrate per card color |
| Aperture | f/8–f/11 (full slab sharp) |
| ISO | 100–200 |
| Format | RAW → export WebP master |
| Polarizer | Optional — reduces case glare without losing label |

### Slab handling
- Clean microfiber on case before each shot
- Slab never leaves case for photography
- Log cert # on shot sheet before and after session
